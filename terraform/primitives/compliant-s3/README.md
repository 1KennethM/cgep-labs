This Terraform primitive configures an S3 data bucket and a separate access-log bucket in us-east-2. It demonstrates technical safeguards mapped to NIST SP 800-53 controls SC-28, AU-3, AU-6, CM-6, and AC-3 through AES256 encryption, access logging, required tags, versioning on the data bucket, and public-access blocking on both buckets. Terraform plan and state evidence is stored in evidence/lab-2-3/. These settings support the selected controls; they do not constitute a complete organizational compliance assessment.
